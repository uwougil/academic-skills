# 英文论文结构化翻译 Skill

## 概述

采用**两遍法**（Two-Pass）将英文物理论文结构化翻译为中文。

### 何时使用
- 用户说"翻译这篇论文"、"translate this paper"、"帮我翻译"
- 需要将英文论文、预印本、文献转为中文
- 需要保持原文格式（图片、公式、表格）完整

### Pass 1：分块（Chunking）

将整篇文章按以下类型拆分成连续块，**每个块标注类型**，确保不遗漏、不重叠：

| 块类型 | 标识规则 | 边界 |
|--------|---------|------|
| **title** | 文件首个 `# ` 行 | 到作者行前 |
| **authors** | 标题后的作者名单行 | 到单位行前 |
| **affiliations** | 机构/单位信息行，含数字编号 | 到摘要或正文前 |
| **abstract** | "Abstract" 或文章开头第一段 | 到第一个节标题前 |
| **body** | 正文所有段落 | 从第一个节标题到致谢前 |
| **figure** | 包含 `![](attachment/` 的行及紧跟的 `FIG.` 说明行 | 图片行 + 说明行 |
| **formula** | `$$...$$` 块或 `\begin{equation}...\end{equation}` | 完整公式块 |
| **table** | `<table>` 包裹的内容或 Markdown 表格行 | 完整表格 + 表题 |
| **acknowledgments** | "Acknowledgements" / "Acknowledgments" 部分 | 到参考文献前 |
| **references** | `[数字]` 开头的文献条目 | 到文件末尾 |

分块仅用于内部完整性检查；默认直接进入 Pass 2 并一次性完成译稿。仅当源文件损坏、翻译范围不明确、用户明确要求预览分块，或继续会造成实质性内容风险时，才向用户展示分块清单并请求确认。

### Pass 2：结构化翻译

完成翻译后直接交付完整译稿与简短的结构核验结果。不要因篇幅较长而要求用户重复确认、分段授权或手动触发继续；除非用户主动要求分批交付。

根据块类型采用不同的翻译格式。

#### 格式规则总表

| 块类型 | 翻译策略 | 引用处理 |
|--------|---------|---------|
| **title** | 逐句翻译 | 不处理引用 |
| **authors** | 姓名不翻译，逐字保留原文 | — |
| **affiliations** | 逐句翻译 | 不处理引用 |
| **abstract** | 逐段翻译 | 文中引用转为注脚 |
| **body** | 逐句翻译 | 文中引用转为注脚 |
| **figure** (图片行) | 不翻译，保留 `![](...)` | — |
| **figure** (图注行 e.g. `FIG. 1.`) | 逐段翻译 | 文中引用转为注脚 |
| **formula** | 不翻译 LaTeX，保留原样 | — |
| **table** | HTML→Markdown 表格，翻译表头和单元格文字 | 不处理引用 |
| **acknowledgments** | 逐句翻译 | 不处理引用 |
| **references** | 不翻译，仅清理格式 | — |

---

#### 逐句翻译格式（用于 title, affiliations, body, acknowledgments）

```
英文原句

中文翻译句

英文下一句
中文翻译句
<空行>
```

**规则**：
- 以英文句号 `.` 为默认断句标志；仅在不拆分缩写、公式、小数、图号或文献条目的前提下，才补充使用 `?`、`!` 和 `—`。
- 在按句号断句前，必须保护带圆点的学术格式：`Fig. 3`、`Figs. 3a,b`、`Table S2`、`Eq. (1)`、`Ref. 5`、`e.g.`、`i.e.`、`et al.`、`vs.`、小数、化学式和期刊缩写。它们内部的圆点绝不能被识别为句末。
- 每个英文句子后必须恰好保留两个换行，再写其对应的一个中文翻译句；中文句后也必须恰好保留两个换行。禁止把多个英文句子或多个中文句子合并为同一段。
- 段落内保留 LaTeX 公式 `$...$` 和 `$$...$$` 在对应的英文句中

#### 逐段翻译格式（用于 abstract, figure captions）

```
英文段落原文...
<空行>
中文翻译段落...
<空行>
```

**规则**：
- 整段读完后写整段中文翻译
- 摘要和每条图注必须采用此英中段落对照格式，不得改为逐句格式或省略中文图注。
- 英文段保持原文换行，中文段正常换行
- 段落间空一行

#### 图片处理

```markdown
![](attachment/xxx.jpg)
英文图注（FIG. N. ...）
<空行>
中文图注翻译
<空行>
```

**规则**：
- `![](...)` 行保持原样不动
- 图片行前后的正文句子**不要被图片截断**——图片应放在所属段落之后
- 如果图片插在段落中间，将整段读完再放图片，然后继续段落后半部分

#### 表格处理

原文 HTML `<table>` 格式 → 重整为 Markdown 表格：

```markdown
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 内容 | 内容 | 内容 |
```

**规则**：
- 表头加粗处理（如需要）
- 翻译表头名称和单元格文字
- 对齐方式使用默认左对齐
- 表格前后各空一行

#### 参考文献与引用注脚

**第一步：清理参考文献条目**
- 删除条目中的多余换行和空格，使每条文献占一行
- 保留原文编号 `[N]`
- 不翻译文献内容

**第二步：文中引用转为 Markdown 注脚**

原文引用格式 | 转换后格式 | 注脚定义
--- | --- | ---
`[1]` | `[^1]` | `[^1]: ...全文...`
`[1–7]` | `[^1][^2][^3][^4][^5][^6][^7]` | 每篇均有注脚
`[18, 20]` | `[^18][^20]` | 每篇均有注脚
`[5–7]` | `[^5][^6][^7]` | 每篇均有注脚

**规则**：
- 连续范围 `[N–M]` 必须展开为范围内每一篇的独立注脚。
- 逗号分隔 `[A, B]` 必须保留每一篇的独立注脚；不得仅保留第一篇。
- 作者姓名行只保留原文，不得调用翻译、音译或在其后增加中文行。
- 多个独立引用如 `[1][2][3]` → `[^1][^2][^3]`，每篇独立注脚
- 注脚定义放在文档末尾，格式为 `[^N]: 完整文献内容（一行）`
- 注脚定义前加标题 `## 参考文献`
- 作者姓名是专有名称，必须保留原文，不得翻译或音译。

**注意**：`[C2∥A]` 这种不是引用，不要转换。引用的特征是方括号内**只有数字**（含逗号、短横线连接的数字）。

### 翻译原则

### 交付前格式检查（易错点）

- 检查每个 Markdown 表格：单元格内只能使用单行 `$...$` 公式，禁止出现跨行 `$$` 块。
- 搜索并清除 Pandoc 原始 HTML 残留（如 `` `<!-- -->`{=html} ``）、断裂的 `$` 分隔符和表格内跨行内容。
- 检查英文与中文表题、图注均完整相邻；图片行本身保持不变。
- 检查独立公式仍使用成对的 `$$`，且不误改为表格内公式。

1. **专业术语一致性**：物理学术语使用公认译名（如 altermagnetism → 交错磁，antiferromagnet → 反铁磁体，spin splitting → 自旋劈裂）
2. **公式和符号**：数学符号、物理量符号、LaTeX 命令**完全保留不翻译**
3. **单位名称**：机构名翻译为中文（如 Sun Yat-sen University → 中山大学），地名翻译（如 Guangzhou → 广州）
4. **人名**：不翻译，保留原文
5. **标点符号**：中文部分使用中文标点（，。！？等），英文部分保持英文标点
